# Mitwirken

1. Issue mit Fehlerbeschreibung oder Feature-Idee erstellen.
2. Änderungen in einem eigenen Branch umsetzen.
3. `./gradlew build` ausführen (Windows: `gradlew.bat build`).
4. Pull Request mit Minecraft-Version, Testschritten und Screenshots erstellen.

Keine fremden Texturen ohne passende Lizenz ins Repository übernehmen. Keine API-Schlüssel oder persönlichen Zugangsdaten committen.
