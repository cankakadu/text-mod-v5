# Installation

1. Java 21 installieren.
2. Minecraft 1.21.11 mit Fabric Loader starten können.
3. Fabric API für 1.21.11 in den `mods`-Ordner legen.
4. Nach einem erfolgreichen Projekt-Build die Datei aus `build/libs/` ebenfalls in `mods` kopieren.
5. Minecraft starten und in den Steuerungseinstellungen nach `TextureCustomizer` suchen.

Hinweis: In dieser frühen Version öffnet der Keybind nur das Menü-Grundgerüst. Texturen werden noch nicht verändert.
